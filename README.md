**CoverCraft — Vice Poster Maker** turns your own photo into multi-panel poster cover art: pick one of four panel layouts (Classic Five, Duo Vertical, Trio + Hero, Magazine Strip), drop a photo into every panel — or stretch one photo across them all — drag and scroll to frame each shot, set a two-line caption in the bundled Anton display face, re-light the whole poster with one of four colour grades (Vice Sunset, Neon Night, Golden Coast, Noir), and export a print-ready PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. Three procedurally drawn sample scenes (Sunset Bay, Neon Boulevard, Pier at Dusk) are built in, so the first poster takes seconds. Everything runs offline in the browser; photos are read on your own device and never uploaded. All artwork, lettering and design are original — no game logos, artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. (Any static file server pointed at `app/` works just as well — there is no build step.)
